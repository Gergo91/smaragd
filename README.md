# Panjshir Smaragd – landing page (preview)

Statikus oldal: `index.html` + `img/` mappa. Nincs build lépés.

## Preview
- **Cloudflare Pages / Netlify / Vercel:** új projekt → ezt a repót kiválasztani → framework: *None*, build command: üres, output directory: `/` (gyökér).
- **GitHub Pages:** Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.

## Élesítés előtt
- A `<meta name="robots" content="noindex, nofollow">` sort ki kell venni az `index.html`-ből.
- Az ajánlatkérő űrlap még nincs bekötve (pl. Formspree, Netlify Forms).
- ÁSZF, adatkezelési tájékoztató, impresszum, sütik oldalak hiányoznak.
- A szaggatottan jelölt „kitöltendő” helyek kitöltése.
- A farsi fordítást anyanyelvi lektorral érdemes átnézetni.
